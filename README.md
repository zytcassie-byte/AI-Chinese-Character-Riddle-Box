
# AI汉字谜盒

基于 FastAPI 构建的大模型应用后端服务，为 AI 字谜游戏提供标准化 RESTful API 接口，支持多会话管理、AI 交互及统一响应格式。

## 技术栈

- Python 3.10+
- FastAPI
- DeepSeek API
- Uvicorn
- Pydantic
- JSON 文件存储

## 安装与配置

### 环境要求

- Python 3.10+
- DeepSeek API Key

### 安装依赖

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
